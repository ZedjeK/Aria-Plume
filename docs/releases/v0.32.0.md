## Aria Plume 0.32.0 — l'extension installée depuis l'application

### Téléchargements

| Fichier | Pour quoi |
|---|---|
| `Aria-Plume-0.32.0-win-x64.zip` | L'application en dossier : celle qu'il faut pour le serveur MCP (chemin fixe de `Aria Plume.exe`) |
| `Aria-Plume-0.32.0-portable.exe` | L'application en un seul fichier, rien à installer |
| `Aria-Plume-extension-0.32.0.zip` | L'extension seule, pour Opera GX et les navigateurs Chromium |

### Nouveautés

- **Installer l'extension depuis l'application** : Réglages → Application → **Extension du navigateur**.
  - Un bouton par navigateur trouvé sur le PC : Chrome, Edge, Brave, Opera, Opera GX, Vivaldi, Chromium, et « Autre navigateur ».
  - L'application copie l'extension dans un dossier fixe à côté de tes réglages, ouvre le navigateur et met l'adresse de sa page d'extensions dans le presse-papiers.
  - Il reste trois clics, guidés : Mode développeur, « Charger l'extension non empaquetée », coller le chemin du dossier. Les navigateurs interdisent à un logiciel d'installer une extension tout seul : ces clics-là reviennent à l'utilisateur.
  - **Mise à jour** : le bouton devient « Mettre à jour dans… » quand l'application est plus récente. Un clic sur ↻ dans le navigateur, et c'est fait.
- L'application embarque maintenant l'extension complète (identique au zip ci-dessus).
