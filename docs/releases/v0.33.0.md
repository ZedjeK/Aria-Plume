## Aria Plume 0.33.0 — correcteur révisé de fond en comble

### Téléchargements

| Fichier | Pour quoi |
|---|---|
| `Aria-Plume-0.33.0-win-x64.zip` | L'application en dossier : celle qu'il faut pour le serveur MCP |

| `Aria-Plume-extension-0.33.0.zip` | L'extension seule, pour Opera GX et les navigateurs Chromium |

### Ce qui change

- **Moins de fausses alertes** : le code (`…`), les adresses web, les courriels, les chemins de fichiers, les identifiants (`srv-fic-01`, `eth0`), les noms propres et marques (Elegoo, Captur) et le jargon informatique courant (switch, backup, firewall…) ne sont plus soulignés.
- **Anglais** : les soulignements ne sont plus décalés après un emoji. Nouvelles règles : participes après have/had (« had went »), accords (« you is », « the children was », « my brother and I was », « one of the disks are »), « there is three », to/too, lose/loose, you're/your, than/then, whose/who's, their/they're, chose/choose, wont/won't, fautes d'orthographe courantes. Suggestions de frappe triées selon le clavier.
- **Français** : son/sont, ce/se, ou/où, ci/si, accord du verbe avec un sujet nom, avec nous, vous et on, accord après « être », participe avec « que » placé avant, pluriel après un déterminant, « pensez à vérifier », futur ou conditionnel selon la phrase, subjonctif respecté. Meilleures suggestions d'orthographe (fesait → faisait, daccord → d'accord, jai → j'ai, remplire → remplir).
- **Texte copié d'un PDF** : les espaces invisibles et les accents décomposés ne cassent plus les mots.

Sur une série de contrôle écrite avant les correctifs : français 90 % des fautes trouvées (85 % avant), anglais 98 % (80 % avant), fausses alertes divisées par quatre.

Moteurs embarqués : Grammalecte 2.3 (GPL-3.0), Harper 2.10 (Apache-2.0), Bergamot 0.4.9 et modèles Mozilla (MPL-2.0), WordNet 3.1. Détails dans `LICENCES-TIERS.txt`.
