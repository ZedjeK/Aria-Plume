## Aria Plume 0.36.0 — l'application rejoint le navigateur et Word

### Téléchargements

| Fichier | Pour quoi |
|---|---|
| `Aria-Plume-0.36.0-win-x64.zip` | L'application en dossier : **celle qu'il faut** pour le pont avec l'extension et pour le serveur MCP |
| `Aria-Plume-0.36.0-portable.exe` | L'application en un seul fichier, rien à installer (sans pont ni MCP : elle se décompresse ailleurs à chaque lancement) |
| `Aria-Plume-extension-0.36.0.zip` | L'extension seule, pour Opera GX et les navigateurs Chromium |

L'exe n'est pas signé : au premier lancement, SmartScreen avertit → « Informations complémentaires » → « Exécuter quand même ».

### Ce qui change

- **Traduction et correction anglaise réparées dans l'application** : sous Windows, la traduction restait bloquée sur « traduction… » et la correction anglaise ne trouvait rien (chemin de fichier mal converti par les moteurs). Un moteur de traduction qui tombe affiche maintenant un message et redémarre tout seul.
- **Tout dans un seul dossier** : `C:\Users\<toi>\.Aria-Plume` (réglages, copie de l'extension, pont, complément Office, données internes). Tes réglages d'avant sont repris au premier lancement.
- **Pont avec l'extension** : Réglages → **Connecter les navigateurs**. L'extension fait corriger et traduire par l'application et partage ses réglages avec elle (un seul dictionnaire, un seul glossaire). L'application démarre toute seule en arrière-plan si besoin.
- **Complément Word** : un bouton « Aria Plume » dans l'onglet Accueil ouvre un panneau Correction, Traduction, Synonymes, Conjugaison. Avec Microsoft 365, les fautes sont soulignées dans le texte et revérifiées pendant la frappe.
- **Mises à jour** : l'application te prévient quand une nouvelle version sort (une demande à GitHub par jour au plus, désactivable ; aucun texte envoyé).
- **Serveur MCP** : `Aria Plume.exe --mcp` prête la correction, la traduction, la conjugaison et les synonymes à Claude Desktop, LM Studio ou toute IA qui parle MCP.

### ⚠️ Une fois, en passant à la 0.36

1. **Extension** : elle a maintenant un identifiant fixe (indispensable pour le pont), le navigateur la voit donc comme une nouvelle extension. Dans l'ancienne : Réglages → **Sauvegarde → Exporter** ; retire l'ancienne carte ; installe la 0.36 (le plus simple : Réglages de l'application → **Extension du navigateur**) ; puis **Importer**.
2. **Réglages de l'application** : copiés de l'ancien emplacement (à côté de l'exe) vers `C:\Users\<toi>\.Aria-Plume`. L'ancien fichier, l'ancien dossier `Aria Plume - extension` et `%APPDATA%\aria-plume` ne servent plus : supprime-les quand tu veux.

### Premiers pas avec les nouveautés

- **Pont** (version zip) : Réglages → Application → **Connexion avec l'extension** → « Connecter les navigateurs ». La popup de l'extension affiche ensuite « Moteur : application ✓ ».
- **Word** : Réglages → Application → **Complément Office** → « Installer le complément Office ». Windows demande une fois d'approuver le certificat local d'Aria Plume (valable uniquement pour `localhost`) : réponds « Oui ». « Tester dans le navigateur » doit ouvrir une page sans avertissement. Redémarre Word : bouton **Aria Plume** dans l'onglet Accueil (sinon : Insertion → Mes compléments → Compléments de développeur). L'application doit tourner pendant que tu utilises le complément.
- **MCP** : Réglages → Application → **Serveur MCP** donne la configuration à copier.

### Aussi depuis la 0.30.1

Les versions 0.31 à 0.35 n'ont pas été publiées : tout est dans celle-ci.

- **Installation assistée de l'extension** depuis l'application, pour Chrome, Edge, Brave, Opera, Opera GX, Vivaldi et Chromium (les navigateurs gardent pour toi les trois derniers clics).
- **Grande révision des règles** : moins de fausses alertes (code, adresses, chemins, identifiants, noms de marque, jargon informatique), soulignements anglais plus décalés après un emoji, texte copié d'un PDF bien lu, nouvelles règles en anglais (have went, you is, there is three, then/than, your/you're…) et en français (sujet loin du verbe, participe passé avec « que », « l' » ou « quel », homophones sans/s'en, voire/voir, plutôt/plus tôt, quel que, futur ou conditionnel, subjonctif…). Sur des séries de contrôle écrites avant les correctifs : français 71 → 87 % des fautes trouvées, anglais 80 → 98 %.

### Limites à connaître

- Les soulignés dans Word demandent un abonnement **Microsoft 365** (service de Microsoft) : avec Office 2021 ou 2024 acheté une fois, le panneau garde la liste des fautes.
- Outlook n'a pas encore son complément (prévu) ; en attendant, le raccourci **Alt+Maj+C** marche dans Outlook avec n'importe quel compte.
- L'exe portable se décompresse toujours d'abord dans le dossier temporaire de Windows.
- Tests sous Windows à confirmer : registre du pont, certificat, Word. Si quelque chose coince, le message affiché aide à trouver.

Moteurs embarqués : Grammalecte 2.3 (GPL-3.0), Harper 2.10 (Apache-2.0), Bergamot 0.4.9 et modèles Mozilla (MPL-2.0), WordNet 3.1. Détails dans `LICENCES-TIERS.txt`.
