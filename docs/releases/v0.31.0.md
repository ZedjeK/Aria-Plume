## Aria Plume 0.31.0 — le serveur MCP

Aria Plume prête maintenant ses outils aux IA : lancé avec `--mcp`, il devient un **serveur MCP** que Claude Desktop, LM Studio ou toute IA qui parle MCP peut utiliser.

### Téléchargements

| Fichier | Pour quoi |
|---|---|
| `Aria-Plume-0.31.0-win-x64.zip` | L'application en dossier : **c'est elle qu'il faut pour le MCP** (chemin fixe de `Aria Plume.exe`) |
| `Aria-Plume-0.31.0-portable.exe` | L'application en un seul fichier, rien à installer |
| `Aria-Plume-extension-0.31.0.zip` | L'extension pour Opera GX et les navigateurs Chromium |

### Nouveautés

- **Serveur MCP** (`Aria Plume.exe --mcp`), quatre outils en lecture seule :
  - `corriger` : chaque faute (extrait, position, explication, suggestions) et le texte corrigé, en français ou en anglais, avec l'option « français soigné » ;
  - `traduire` : français ↔ anglais, avec ton glossaire ;
  - `conjuguer` : tous les temps d'un verbe français ;
  - `synonymes` : groupés par sens et accordés.
- Tes réglages s'appliquent au MCP : dictionnaire personnel, mots ignorés, catégories, glossaire.
- Réglages → Application → **Serveur MCP** : la configuration à copier, avec le bon chemin.
- Compatible avec les clients MCP récents (protocole 2026-07-28) comme avec les plus anciens (poignée de main `initialize`).

Les corrections tournent sur ton PC. Ce que l'IA fait du reste de la conversation dépend de l'IA utilisée : avec une IA locale, tout reste chez toi.

Moteurs embarqués : Grammalecte 2.3 (GPL-3.0), Harper 2.10 (Apache-2.0), Bergamot 0.4.9 et modèles Mozilla (MPL-2.0), WordNet 3.1. Détails dans `LICENCES-TIERS.txt`.
