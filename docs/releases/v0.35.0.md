## Aria Plume 0.35.0 — l'extension et l'application se parlent

### Téléchargements

| Fichier | Pour quoi |
|---|---|
| `Aria-Plume-0.35.0-win-x64.zip` | L'application en dossier : celle qu'il faut pour le pont avec l'extension et pour le serveur MCP |
| `Aria-Plume-0.35.0-portable.exe` | L'application en un seul fichier, rien à installer (sans pont ni MCP) |
| `Aria-Plume-extension-0.35.0.zip` | L'extension seule, pour Opera GX et les navigateurs Chromium |

### ⚠️ Une réinstallation de l'extension, une seule fois

L'extension a désormais un identifiant fixe, indispensable pour parler à l'application. Le navigateur la voit donc comme une nouvelle extension :

1. dans les réglages de l'extension actuelle : **Sauvegarde → Exporter** ;
2. retire l'ancienne carte d'Aria Plume dans la page des extensions ;
3. charge le dossier de la 0.35 (ou utilise **Réglages → Extension du navigateur** dans l'application) ;
4. **Sauvegarde → Importer** le fichier exporté.

Les mises à jour suivantes garderont le même identifiant : plus besoin de recommencer.

### Ce qui change

- **Pont entre l'extension et l'application** : dans l'application (version zip), **Réglages → Connexion avec l'extension → Connecter les navigateurs**. L'extension confie alors l'analyse, la traduction, la conjugaison et les synonymes à l'application, et les deux partagent les mêmes réglages : un seul dictionnaire, un seul glossaire, les mêmes mots ignorés partout.
- **L'application démarre toute seule** en arrière-plan, près de l'horloge, quand l'extension en a besoin. En attendant, et si elle ne répond pas, l'extension corrige avec son propre moteur : rien n'est jamais bloqué.
- **Première connexion** : les réglages des deux côtés sont réunis (dictionnaires, glossaires, termes gardés, mots ignorés et sites exclus fusionnés).
- **Pastille « Moteur : application ✓ »** dans la popup de l'extension quand le pont est actif.
- **Sans droits administrateur et sans réseau** : inscription dans `HKEY_CURRENT_USER` pour Chrome, Opera, Opera GX, Vivaldi, Edge, Brave et Chromium ; le navigateur n'autorise que l'extension Aria Plume, et l'application exige un jeton stocké dans un fichier lisible par toi seul. Aucun port n'est ouvert. **Déconnecter** retire tout.
- Nouvelle permission de l'extension : `nativeMessaging` (parler à l'application installée sur ton PC). Sans l'application, l'extension fonctionne seule, comme avant.

Moteurs embarqués : Grammalecte 2.3 (GPL-3.0), Harper 2.10 (Apache-2.0), Bergamot 0.4.9 et modèles Mozilla (MPL-2.0), WordNet 3.1. Détails dans `LICENCES-TIERS.txt`.
